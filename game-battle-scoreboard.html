共通点探しゲーム

加点 ＋ ボーナス
＋ 共通点の個数　（基本加点）
チームで見つけた共通点を1つにつき1点加点します。
🌟 ボーナス：珍しい・面白い共通点はボーナス加点あり。司会者が裁量で追加点を入力してください。

トランプ数字合計

加点のみ
＋ メンバー全員のトランプ合計値
各メンバーが引いた1枚のトランプの数字を全員分合計した値を、そのまま得点として入力します。A=1、J=11、Q=12、K=13。
⏱️

しりとり

敗者のみ減点
敗者チームに － 続いた単語数 × 0.5
タイマーが鳴った時点で止めてしまったチームが減点対象。長く続いた末に負けるほど大きなダメージになります。他のチームは 0 点のまま。
例：30単語続いてから負けた場合 → −15点
⚔️

黒ひげ危機一髪

敗者のみ減点
敗者チームに － 飛んだ時の剣の本数
黒ひげが飛んだ瞬間に刺さっていた剣の本数をそのまま減点。多く刺さってから飛ばすほど痛い。他のチームは 0 点のまま。
例：剣が14本刺さった状態で飛んだ場合 → −14点
🟫

ジェンガ

敗者のみ減点
敗者チームに － 倒した時の抜けブロック数
タワーが倒れた時点で抜けていたブロックの総数をそのまま減点。高く積み上げてから倒すほど大ダメージ。他のチームは 0 点のまま。
例：28個抜いた状態で倒した場合 → −28点
